# Firas Slama — Personal Portfolio Website

A responsive, static one-page portfolio website built with plain HTML, CSS and JavaScript.

## Website files
- `index.html` — portfolio content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and small interactions
- `assets/` — favicon and portfolio photographs

## Publish with GitHub Pages
1. Open the repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to finish deploying.

Before sharing publicly, confirm CV access, photo permissions, project metrics, role dates and contact details.
